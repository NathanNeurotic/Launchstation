Install & Update

wLaunchELF R3Z is portable: the ELF can live on any filesystem that the launcher can read.

Minimum install

BOOT.ELF

That is sufficient for normal dashboard and file-management use.

Recommended install

wLaunchELF_R3Z/
├── BOOT.ELF
├── BGM.ADP                  optional
├── WLE-CLOUD.CNF            optional; create from example
└── WLE-CLOUD-CA.PEM         optional; native cloud TLS

Configuration discovery

The project keeps classic LAUNCHELF.CNF compatibility and a dashboard settings store. A custom CNF path can be selected in Settings. Saving can target the configured folder, next to the ELF or a memory-card SYS-CONF location.

Updating safely

  1. Download the newest packed ELF.
  2. Back up the current ELF and configuration.
  3. Replace the ELF first.
  4. Replace sidecars when release notes say their format/content changed or when enabling a new feature.
  5. Boot and review Settings before overwriting older configuration copies.

Portable sidecar strategy

For a self-contained installation, keep BGM and cloud support files beside the program. For multi-console setups, use explicit save/loader paths so shared and per-console state are intentional rather than accidental.
