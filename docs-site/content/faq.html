FAQ

Does R3Z replace classic wLaunchELF?

No. It adds a modern dashboard and new workflows while retaining classic browser/tools and compatibility foundations.

Why are some ELFs missing from Apps?

Apps scans only configured roots. Add the exact folder in Settings → Home & applications → Application folders.

Why does File Browser still show seconds?

Keeping seconds was an explicit project decision. The fix was to improve size/date column spacing rather than remove timestamp precision.

Does wLaunchELF include Neutrino?

No. It finds and launches an external Neutrino install.

Does it include POPStarter?

No. POPStarter is external; wLaunchELF uses an explicit path and device-specific fallback search.

Does Google Drive upload automatically?

No. Cloud support is optional and “Google Drive after IGR” is off by default.

Can I use these docs offline?

Yes. Download wLaunchELF_R3Z-Documentation.zip. It contains the same generated HTML, assets and search index as GitHub Pages.

Does CI mean every device is hardware-tested?

No. CI verifies source contracts, builds, links and loader memory layout. Hardware-specific timing, bridges, displays and external-core behavior still require console testing.
