Troubleshooting

Identify the failing layer first: hardware/device, filesystem, Launchstation launch preparation, external core, or the target application/game.

Device says Not checked

Open it. Not checked is intentionally actionable: the lazy driver has not yet established presence. A confirmed Not connected result is different. Entries that cannot exist on your console (for example HDD/ATA on a deckard or PSX, or iLink on consoles without the port) are hidden rather than shown as absent.

USB path/unit changed

Do not assume mass0:. Multiple drives, MX4SIO and attach order can affect unit numbering. Start from the dashboard's USB / MASS device and let the root discovery logic identify what is available. Tools > USB unit diagnostics can show the cached unit mask without I/O; a manual probe is a synchronous IOP call and can freeze a failing console.

MMCE and MX4SIO conflict

They share the memory-card ports and cannot be active together. Switching between them restarts the IOP drivers. If a card or adapter stops responding after a switch, use Tools > Reboot IOP, then open only the device you need.

PS2 ISO will not start

  1. Browse/read the ISO from the same source device.
  2. Confirm it is an ISO9660 image.
  3. Set a Neutrino path explicitly (Settings > Launching > Disc & image loaders) to remove search-order ambiguity.
  4. Confirm Neutrino has modern config/system.toml or legacy adjacent system.toml.
  5. Check that the Neutrino switch under Disable Neutrino support is Off.
  6. Try a known-good ISO on the same backend.

PS1 VCD will not start

Confirm the VCD is in a supported POPStarter layout, then set POPStarter explicitly. HDD POPS layouts have special argument construction; a raw browser path is not necessarily a valid POPStarter command line.

PS1 CUE/BIN will not start

The image must be under <Ember directory>/games/<Game>/, bios.bin must be supplied by you, and ember.elf must be present or available from the configured Ember directory. See Ember.

After a successful update restart Launchstation. If the new build misbehaves, rename the .ELF.BAK over the ELF to roll back. See Install & Update.

Clock sync fails

The message names the failed step. Socket server (PS2IPS) could not be loaded or Could not connect to the network socket server point at the Ethernet stack; PC CARD CompactFlash is using the network adapter means the CF adapter owns the bus. DNS lookup failed, reply timed out or server refused request are network or server-side: check IP/gateway/DNS and retry. Launchstation sends up to two attempts to 0.pool.ntp.org (5 s each).

Google Drive link/upload fails

Confirm network/IP first, then PS2 clock/time, then any custom OAuth client or CA bundle under Advanced setup. Certificate validation can fail when the RTC is materially wrong (use Settings > Network > Sync PS2 clock from Internet or set the clock). DNS remains synchronous in PS2IP and can behave differently from the later socket timeout path.

Settings did not stick

Settings preview changes immediately but are written only when you choose Save changes (the Settings changes menu). If an earlier save failed the menu offers Retry failed saves. Check that the configuration folder is writable (Settings > System > Configuration folder).

DualShock controller not recognized

Only the -DS package includes the PS3/PS4 USB/Bluetooth drivers. Confirm you started LAUNCHSTATION-DS.ELF. This variant still needs console validation with your controller and concurrent storage; report the controller model and connection type.

Colored bars before opening ELFs

Launchstation can intentionally draw a short Game ID identification signal for compatible video adapters. To disable the colored bars, open Settings > Launching > Game ID output and turn off the application Game ID launch signal. Normal start-up boot-check text is hidden in production builds.

Top-of-dashboard flicker

The known fast selector oscillation has been removed. If flicker persists, report video mode, display/cable, interlace/progressive mode, theme, and whether the symptom occurs in other screens too.

Build problems

Mixing toolchains is the usual cause: Mbed TLS (.cloud-deps/) and libjpeg-turbo (.jpeg-deps/) must be rebuilt after switching between LLVM and GCC (PS2BUILD_TOOLCHAIN), and a GCC-built archive linked into a Clang build fails at link time. Re-run scripts/build_cloud_tls.sh and scripts/build_jpeg.sh with the toolchain you intend to use. See developer notes.

Good bug report

  • Exact commit/build (Tools > About Launchstation) and package or packed ELF SHA-256.
  • Variant: standard or -DS.
  • Console model and video mode.
  • Source device/backend and filesystem.
  • Minimal reproduction steps.
  • Whether the problem also occurs with the 2026-10-08 baseline or a previous .BAK.
  • For Neutrino/POPStarter/Ember, external-core version and resolved path.
