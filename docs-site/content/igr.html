IGR Return & Backup

The wLaunchELF IGR path can return from a game, protect MMCE state and then continue according to the configured policy.

Automatic local backup

If enabled, a changed active MMCE card is written to local history before the post-IGR destination is entered. An unchanged card can be skipped without being treated as an error.

Optional cloud phase

Google Drive synchronization is a second phase and requires an already linked account. It is off by default and never replaces the local backup as the primary safety copy.

After-IGR behavior

The dashboard exposes an after-IGR policy and optional ELF path. This allows a return to the dashboard or another configured destination after backup work finishes.

Failure policy

Backup and cloud errors are surfaced as status/toast messages. The design avoids silently pretending that a failed write or failed cloud operation succeeded.
