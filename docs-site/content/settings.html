Settings Reference

Dashboard settings are grouped by purpose and retain explicit unsaved-state behavior.

Major groups

GroupExamples
AppearanceTheme, selection style, icon backing, clock/date, screen position.
Home & applicationsApplication folders, startup section/view, Home shortcuts.
SoundDashboard audio and BGM behavior.
InputConfirm/cancel mapping, USB keyboard, virtual keyboard layout.
LaunchingNormal ELF IOP reset, ESR, OSDSYS, POPStarter, Neutrino and launch keys.
Storage & devicesUnavailable-device visibility, MMCE history and storage behavior.
NetworkIP, netmask, gateway and network-oriented feature controls.
SystemCore runtime options and maintenance actions.

Unsaved state

Settings compare current serialized values with the session snapshot. Touching a control and returning it to the original value does not leave a false dirty flag. Save failures remain visible and can be retried.

Path pickers

Program/file settings use the native browser picker. POPStarter and Neutrino both have explicit ELF path fields. Memory-card aliases are retained where the classic configuration supports them.

Unavailable devices

Show unavailable devices controls whether confirmed-missing devices are displayed. Hidden devices are removed from navigation as well as drawing. Unprobed devices remain actionable.

Reset actions

Display/theme reset actions restore known project defaults so users do not need to manually reverse each visual setting.
