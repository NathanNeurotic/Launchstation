Markdown wiki source

The editable Markdown guide collection is kept in the main repository at docs/wiki/:

  • Home, Current features
  • Releases and recovery, MMCE recovery
  • Theme and wallpaper guide

These pages are reviewable alongside the runtime changes they document. When a push to master changes docs/wiki/, the authored site pages, the manifest or the wiki sync script, the Synchronize GitHub Wiki workflow copies them into the repository's separate GitHub Wiki (it first needs one starter page created in the Wiki tab). GitHub Pages is built independently from docs-site/ and published to gh-pages; neither generated output should be edited by hand.

Offline copy

Generate the whole site, including the search index, as a ZIP: python3 docs-site/build.py --out build/docs --zip build/Launchstation-Documentation.zip. The same archive is attached as a workflow artifact and published under downloads/ on the site as Launchstation-Documentation-<build>.zip. The build number is the commit count of the documentation build; it equals an app ZIP's number only when both come from the same commit, because the documentation is only republished when docs-site/ changes.
