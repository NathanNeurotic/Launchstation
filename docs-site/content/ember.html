PS1 Image Launching · Ember

Ember is the second PS1 core beside POPStarter. The two do not compete for a preference: .VCD uses POPStarter, while Ember's own folder/image layout uses Ember automatically.

External core and BIOS
Ember is not embedded in r3LaunchELF_ATTDASH. Set an optional Ember directory under Settings → Launching → Disc & image loaders. The target game's own umbrella still needs the user's PlayStation BIOS as bios.bin (exactly 512 KB). If the target umbrella lacks ember.elf, r3LaunchELF_ATTDASH can copy the configured ember.elf into that umbrella once before launch.

Save-safe layout

The umbrella folder can be named anything and live anywhere on the device.

DEVICE:/
└── MY-EMBER/
    ├── ember.elf
    ├── bios.bin
    └── games/
        ├── Spyro 2 (Ripto's Rage)/
        │   ├── game.cue
        │   ├── track01.bin
        │   ├── MC1.vmc          created/used by Ember
        │   └── MC2.vmc          created/used by Ember
        └── Another Game/
            └── game.bin

Select a .CUE, .BIN or PS1 .EXE directly inside the game folder. r3LaunchELF_ATTDASH derives the bare folder name and passes that to Ember.

Why loose CUE files are refused

Ember can resolve looser layouts, but its memory-card path is always composed as games/<argument>/MC1.vmc and MC2.vmc. A loose games/Game.cue can boot while silently making the save path impossible. The browser therefore offers only the folder layout that can both launch and save correctly.

Launch contract

Ember derives its working directory from target argv[0], so r3LaunchELF_ATTDASH preserves the real live path to ember.elf as target argv[0]. The bare game-folder name is the only game argument. Names containing path separators, a colon, a leading .., or more than 180 characters are refused.

Keep-IOP handoff

Ember does not reset/rebuild the IOP device stack. r3LaunchELF_ATTDASH therefore keeps the source device mounted across the handoff. On APA/PFS, the Ember partition is mounted writable with write-through so Ember's VMC files persist after reset/power-off.

Troubleshooting

  1. Confirm the selected image is directly under <umbrella>/games/<Game>/.
  2. Confirm <umbrella>/bios.bin exists and is exactly 512 KB.
  3. If <umbrella>/ember.elf is missing, set a valid Ember directory so r3LaunchELF_ATTDASH can stage the executable into the target umbrella.
  4. Do not reset the IOP for Ember; the dedicated handoff ignores the normal ELF reset preference.
