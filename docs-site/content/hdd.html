Internal HDD

r3LaunchELF_ATTDASH retains classic APA/PFS management while surfacing HDD state through the dashboard.

APA / PFS

The Devices card is labeled Internal HDD (APA). Opening it while unprobed starts the HDD stack and exposes partitions through existing browser logic. A Not checked card is intentionally actionable; confirmed-absent hardware is not.

HDD Manager

Tools → HDD Manager exposes classic partition-management functions such as create, remove, rename, expand, format and HDL-related information. Partition operations can destroy data; make backups before resizing, removing or formatting anything.

Path forms

Browser paths commonly use hdd0:/partition/path/to/file. Internally a mounted filesystem is represented as pfsN:. Loader helpers retain the owning APA partition so an ELF on PFS remains reachable through teardown/handoff.

Common partition workflows

__common is frequently used for shared application/data storage. The timestamp organizer also understands hdd0:/__common/ alongside memory-card roots.

ATA / exFAT is separate

ATA/exFAT storage is not the same thing as APA/PFS. It uses the BDM/FATFS path and appears as its own device class where compiled. Neutrino can use the ATA backend for an ISO on this path.
