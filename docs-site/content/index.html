What this project is
Launchstation keeps the power-user roots of LaunchELF/uLaunchELF/wLaunchELF while adding a PS2-style dashboard, safer device handling, modern storage paths, searchable app discovery, richer file operations, MMCE workflows, PC interoperability and external game-core handoffs. The classic browser remains available; the dashboard is the primary interface.

Design goals

  • Device-agnostic launching. Work from the device the user actually browsed instead of assuming mass0 or mc0.
  • Demand-load expensive stacks. Drivers and networking stay out of startup until needed.
  • Keep classic functionality. Dashboard actions wrap proven Launchstation operations instead of discarding them.
  • Visible state. Not checked, absent, busy, unsaved changes and background work are explicit.
  • Hardware-first validation. CI catches structural/link/layout regressions; device behavior is still verified on consoles.
