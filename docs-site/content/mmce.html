MMCE

MMCE is both a first-class storage device and the source for versioned memory-card backup workflows.

Browsing

MMCE devices are represented through the device layer and can be opened on demand. The code does not reduce all MMCE use to one hard-coded slot; active device/card state is tracked explicitly.

Backup integration

The active MMCE card image can be exported into local history. The workflow verifies the result, can retain a configured number of versions and avoids creating another copy when the card is unchanged.

IGR workflow

When enabled, returning through the r3LaunchELF_ATTDASH IGR helper can create the local backup before continuing to the configured after-IGR destination. Optional Google Drive sync runs after local success.

Neutrino

Neutrino has a dedicated mmce backend. r3LaunchELF_ATTDASH can also discover a complete /neutrino/ install on the game device or on either memory-card slot.
