Privacy Policy

Launchstation is free, open-source PlayStation 2 homebrew. It has no accounts, no analytics and no servers of its own. This page explains the little data it handles and where it goes.

Summary

  • Launchstation does not collect, sell or share personal data. Its developers receive nothing from your console.
  • There is no telemetry, advertising, crash reporting or tracking.
  • Everything Launchstation stores stays on your own PS2 storage (memory card, USB, HDD and similar).
  • Network features run only when you use them, and talk directly to the services listed below. Nothing connects to the Internet during an ordinary boot.

What is stored on your console

All of these are plain files on your own storage, and you can read, copy or delete them:

  • Settings and library: DASHBOARD.CNF, DASHAPPS.CNF (favorites, pins, recently launched applications), DASHLIB.CNF (cached application library), the classic LAUNCHELF.CNF, and IPCONFIG.DAT (the console's IP, netmask and gateway), saved beside the ELF or in SYS-CONF.
  • Backups: verified memory-card images under WLE-MMCE-Backups and any RECOVER-*.mcd files you create. These are full card images and contain whatever save data is on the card.
  • Cloud files: WLE-CLOUD.TOK (the Google refresh token, stored as readable text) and, only if you configure them, WLE-CLOUD.CNF (a custom OAuth client ID and secret) and WLE-CLOUD-CA.PEM. Keep them private and do not post them in bug reports.
  • Optional per-game data: Neutrino profiles, themes and similar files you create.

Google Drive backup (optional)

If you choose Link Google Drive, you authorize Launchstation on a phone or computer with a short code from Google. Launchstation requests only the https://www.googleapis.com/auth/drive.file scope, which lets it see and manage only the files and folders it creates (your memory-card backups in the WLE-MMCE-Backups folder). It cannot read the rest of your Google Drive.

What is sent, and only to Google over verified HTTPS (oauth2.googleapis.com, www.googleapis.com, and Google content hosts under googleusercontent.com for downloads):

  • the OAuth client ID (and its secret) of the Launchstation build, the device code during linking, and later the refresh token and short-lived access tokens;
  • when you upload: folder names, backup file names, the full contents of the memory-card backup files, and a private checksum (wle_sha256) stored as app-private file metadata so unchanged backups are not uploaded twice;
  • when you browse or recover: Drive listing requests for the app-created folder and, for recovery, a download of the snapshot you select.

The access token is only ever sent to Google's API host, even when a download is redirected. Launchstation's developers never receive your token, your backups or your Google account details. The Launchstation OAuth client identifies the app to Google; it is not a way for the developers to access your Drive.

To stop access, choose Disconnect Google Drive in Launchstation, which deletes the local token (it does not contact Google), and remove Launchstation at Google Account > Third-party access to revoke the grant. Files already uploaded stay in your Drive until you delete them.

Launchstation's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data received from Google is used only to provide and improve the backup, listing and recovery features you invoke, is never used for advertising, and is not transferred to anyone.

Other network features

  • Check for updates contacts api.github.com (the latest release's metadata and a comparison between your installed commit hash and the release commit) and, if you accept an update, downloads the package from github.com. The request identifies itself as Launchstation-PS2. It uses the bundled WLE-UPDATE-CA.PEM and never involves Google. GitHub's own privacy statement applies to those requests.
  • Clock synchronization, when you use Sync PS2 clock from Internet, sends an ordinary SNTP time request to all three of time.google.com, time.cloudflare.com and pool.ntp.org. A random timestamp is the only content; no personal data is sent.
  • Local-network services (FTP, the PS2Link host, UDPFS, PC remote commands and game transfers) connect only to computers on your own network that you set up. They are unauthenticated by design, so use them on a trusted network (see Network exposure).
  • External launchers such as Neutrino, POPStarter and Ember are separate programs that Launchstation starts. They have their own behavior and terms and are not covered by this page.

Like any internet request, these services can see your public IP address. Launchstation adds no identifiers of its own. No other part of Launchstation makes Internet connections.

Children

Launchstation does not knowingly collect data from anyone, including children.

Changes and contact

Changes to this policy are published on this page and in the project's GitHub repository. Questions can be raised as a GitHub issue or sent to the support email shown on the Google consent screen.
