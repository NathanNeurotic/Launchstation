Saves, PSU & Timestamp Tools

r3LaunchELF_ATTDASH keeps the classic memory-card/save toolbox while making destructive actions and timestamp manipulation more explicit.

PSU create and extract

The browser uses explicit Create PSU and Extract PSU wording so the direction of the conversion is clear. PSU containers are useful for moving save folders while preserving PS2 metadata that ordinary host filesystems do not represent well.

Copying saves

Copy/paste and PSU workflows retain the specialized handling required by memory-card folders. Avoid treating a PS2 save as an arbitrary PC directory when preserving icon metadata, attributes and timestamps matters.

Virtual memory cards

VMC image files can be mounted through the File Browser where supported, exposing their contents through the normal file-management path.

Timestamp manipulation

wLaunchELF can edit and organize directory timestamps. This is especially useful for OSDSYS/HOSDSYS ordering and icon-based exploit folders whose position is influenced by timestamps.

Organizer roots

The organizer supports memory-card roots and hdd0:/__common/. Sorting modes include manual ordering, A–Z and SAS-style timestamps; game-save handling is kept distinct where appropriate.

Exploit-folder protection

Dangerous modifications/deletions of known exploit-style memory-card folders trigger warnings. That guard exists because a routine rename/delete can turn a bootable exploit card into an unbootable one.
