Each app folder contains its packed executable and title.cfg, including its title and boot filename. ZIP and PSU file payloads match. Preserve existing settings and optional sidecars when upgrading.

DualShock build

The -DS packages enable the inherited PS3/PS4 USB/Bluetooth controller drivers. The standard packages use the standard PS2 pad driver. Build checks do not establish controller and storage coexistence on a real console.

Integrity and native updates

The native updater selects the PSU matching its controller variant, verifies GitHub's SHA-256 asset digest, extracts only the matching ELF, and validates its PS2 ELF header before staged replacement with rollback. Older builds that expect standalone ELF assets require one manual upgrade from the matching ZIP. For bug reports, record the commit and package or ELF SHA-256.

Optional music, cloud configuration and TLS certificates are available under res/ in the source repository. Offline documentation can be generated with python docs-site/build.py --out build/docs --zip build/Launchstation-Documentation.zip.
