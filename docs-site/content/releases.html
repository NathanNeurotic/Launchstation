Integrity

Automated builds print SHA-256 hashes in the workflow log and publish r3LaunchELF_ATTDASH.ELF.sha256 beside the packed release ELF. The native updater refuses to replace the running executable unless the staged ELF matches that published SHA-256 and passes the PS2 ELF header check. When comparing tester results, use the exact BOOT.ELF hash instead of the filename alone.
