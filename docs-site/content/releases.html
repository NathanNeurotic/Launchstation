Integrity

GitHub publishes a SHA-256 digest in the release metadata for uploaded assets. The native updater reads the digest for r3LaunchELF_ATTDASH.ELF directly from GitHub, hashes the downloaded ELF, and refuses to replace the running executable unless the values match and the PS2 ELF header is valid. No separate checksum text file is required. When comparing tester results, use the exact BOOT.ELF hash instead of the filename alone.
