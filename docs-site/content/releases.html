Upgrading an older installation: Builds published before the repository was renamed may not follow GitHub API redirects during their built-in update check. If that check fails, download the current BOOT.ELF or Launchstation.ELF and replace the old executable manually once. Subsequent updates use the canonical repository endpoint. The legacy r3LaunchELF_ATTDASH.ELF release asset is retained for filename compatibility.

Integrity

GitHub publishes a SHA-256 digest in the release metadata for uploaded assets. The native updater reads the digest for Launchstation.ELF directly from GitHub, hashes the downloaded ELF, and refuses to replace the running executable unless the values match and the PS2 ELF header is valid. No separate checksum text file is required. When comparing tester results, use the exact BOOT.ELF hash instead of the filename alone.
