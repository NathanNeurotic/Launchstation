Display, Themes & BGM

The dashboard is PS2-inspired but deliberately configurable rather than forcing one presentation.

Selection presentation

Selection style can be changed instead of forcing a single hue/glow. Selected and unselected device cards use the same geometry; focus adds emphasis without resizing/reflowing the card.

Icon backing

Control/menu icon backing can be enabled or disabled explicitly. This option came from tester feedback rather than being baked into a single theme.

Clock and date

The dashboard clock can follow system 12/24-hour behavior or theme overrides, optionally show seconds and use configured date order/placement. File metadata retains seconds independently of the clock setting.

Motion

Top tabs, selection movement, OSD orbs and marquee effects use bounded smooth animation. The former fast sinusoidal header overshoot was removed because it could appear as top-of-dashboard video flicker on interlaced displays.

Background music

BGM.ADP is optional. Put it where wLaunchELF can resolve the sidecar. A missing music file does not prevent the dashboard from booting.

Reset display/theme

The reset action restores video mode/centering and project theme defaults, useful when experimentation makes text, selection or offsets difficult to recover manually.
