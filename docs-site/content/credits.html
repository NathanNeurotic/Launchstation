Credits & Licenses

r3LaunchELF_ATTDASH exists because of decades of PlayStation 2 homebrew engineering.

Direct base: wLaunchELF_R3Z

This project is directly based on wLaunchELF_R3Z by R3Z3N / Saildot4K. Its device support, lazy-loading architecture and R3Z feature work are a major foundation of this fork and are credited explicitly.

Fork creator: johnson-cooper

johnson-cooper created this fork and handed the project over to NathanNeurotic / Ripto to maintain and continue improving. This project exists in its present forked form because of that work and handoff.

Earlier lineage

wLaunchELF_R3Z itself descends from wLaunchELF, uLaunchELF and the original LaunchELF. Credit also belongs to those authors/contributors, the ps2dev/PS2SDK community and the many driver/filesystem developers whose work makes modern PS2 storage and networking possible.

Current project

Maintained by NathanNeurotic / Ripto. Repository contributors and testers are credited in project files and release history. TnA is thanked for all his insight and support.

External projects and collaborators

  • Neutrino — external PS2 device/game core used for ISO handoff.
  • POPStarter — external PS1 launcher used for VCD handoff.
  • Mbed TLS — TLS implementation used by native cloud under its upstream license.
  • Google Drive APIs — public OAuth/Drive APIs used by the clean-room native client.
  • oMrRexD — R3Z/FTP and PC-side ecosystem reference and collaboration.
  • Zack and FitthFox — extensive dashboard/File Browser UX testing and feedback that drove the current layout and behavior.

Cloud implementation boundary

The native Google Drive integration was implemented against public Google APIs; no SD2Cloud source is incorporated. Third-party dependencies remain under their upstream licenses.
