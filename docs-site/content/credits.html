Credits, Third-Party Projects & Licenses

LAUNCHSTATION builds on decades of PS2 homebrew. This page distinguishes upstream code, checked-in components, external programs launched by the user, referenced projects and community contributions.

Project lineage and maintainers

wLaunchELF_R3Z by R3Z3N / Saildot4K is the direct upstream base. The earlier wLaunchELF / uLaunchELF / LaunchELF developers and ps2dev community retain credit for the underlying launcher lineage. johnson-cooper created this fork and transferred maintenance; NathanNeurotic (Ripto) is its current maintainer.

Special thanks to techwritescode for collaboration, TnA for insight and support, oMrRexD for PC/R3Z ecosystem collaboration and reference, and zackcage6 and FitthFox for dashboard and File Browser testing and UX feedback. Contributors and testers also appear in the repository's Git history, merged pull requests and release notes.

External projects and dependency inventory

Attribution below does not mean every third-party program is distributed by LAUNCHSTATION. The role of each project is specified.

  • wLaunchELF_R3Z — Direct upstream base by R3Z3N / Saildot4K; earlier LaunchELF, uLaunchELF and wLaunchELF contributors retain credit.
  • ps2dev / PS2SDK — Toolchain, SDK and upstream foundations of vendored memory-card, HDD, networking and filesystem code.
  • ps2-mmce/mmceman — MMCE driver lineage and device protocol: local driver sources and precompiled module. Credit the upstream MMCE developers, including Wisi and Maximus32 for earlier SIO2 work.
  • RiptOPL / Open-PS2-Loader — Source/reference of the updated usbd-ra USB driver imported during USB recovery; also relevant to the OPL IGR return workflow.
  • ps2ftpd — Jesper Svennevid's FTP server; checked-in legacy source at iop/oldlibs/ps2ftpd/, accompanied by Academic Free License v2.0.
  • libcdvd (legacy) — Legacy checked-in IOP CDVD library; copyright A. Lee and Nicholas Van Veen. Its file-level license restricts commercial use. See iop/oldlibs/libcdvd/license.txt.
  • DS34 controller drivers — Inherited PS3/PS4 controller support and local DS34 driver sources, with credit to Alex Parrado and the R3Z/PS2 community.
  • audsrv — Locally retained PS2 audio server package (packages/world/audsrv); LGPL-2.0 identified in packages/README.md.
  • libogg / libvorbis — Retained compiled codec packages in packages/world/ogg and packages/world/vorbis; BSD-style licensing described in packages/README.md.
  • Mbed TLS — Native cloud HTTPS dependency, built from upstream source; Apache-2.0 according to native cloud documentation.
  • Roboto font — Bundled font notice: docs/licenses/Roboto-COPYRIGHT.txt.
  • Neutrino — External PS2 ISO loader maintained independently; the ELF and its configuration are not bundled.
  • POPStarter — krHACKen's independent PS1 VCD launcher, not included with Launchstation.
  • Ember — Gageformer's external PS1 core, not bundled; beta builds have their own distribution terms.
  • PS2Link / PS2Client — Upstream network development and remote-access ecosystem (including the separate PC client).
  • UDPFSD server — pcm720's PC-side UDPFS server referenced by supported network storage workflows.
  • OSDMenu / launcher — pcm720's reference for KELF forwarders and PS2 boot workflows; referenced, not necessarily included.
  • KELFTool — xfwcfw's separate KELF tooling referenced for PS2KEYS.dat and KELF workflows.
  • HDD-OSD Icon Generator — CosmicScale's helper for HDD/APA icon resources; referenced, not bundled.
  • PixelFX RetroGem — External hardware ecosystem for the optional RetroGem Game ID feature.
  • Google Drive / OAuth / Google PKI — Public protocol/API and certificate sources used by the original native Drive client; no Google endorsement is implied.
  • oMrRexD / R3Z PC ecosystem — Compatibility and integration reference for PC-side remote commands and transfers.
  • SD2Cloud — Related backup ecosystem used for capability comparison only; the native Drive client does not incorporate SD2Cloud source.

Additional graphics, image and bootloader projects

  • gsKit and dmaKit — the PS2 dashboard graphics libraries; gsKit credits Chris "Neovanglist" Gilbert and contributors, under upstream Academic Free License version 2.0.
  • libpng and Independent JPEG Group / libjpeg — image decoding and library interfaces behind the native viewer. See relevant linked library notices.
  • PS2BBL by El_isra and PS2BBLE by R3Z3N — independent PS2 bootloader projects, not synonymous with Launchstation's exploit installer.
  • LoadBOOTer — a named option in the inherited memory-card exploit installer; authoritative author and source are not verified in this repository audit.
  • ESR, FreeMcBoot and PSBBN — separate boot tools, software environments or compatible formats referenced in the docs; their code is not implied to be distributed.

Further library and subsystem credits

The native image viewer relies on libpng and libjpeg support; the EE/IOP graphics, filesystems, audio and networking stacks include PS2SDK and upstream library contributors. Check the originating source file headers, included package metadata and the relevant upstream license notices when redistributing builds or source archives. The PS2Key material, user games, PS1 BIOS and external emulator executables are not supplied by this repository.

Cloud implementation boundary

The Google Drive client is implemented against Google's published APIs; SD2Cloud source code was not incorporated. External launchers remain independently maintained and licensed.

License notices and distribution

There is no repository-root LICENSE file at this audit snapshot. Do not infer one blanket license for every file or third-party module. Checked-in notices include ps2ftpd AFL-2.0, libcdvd's restrictive historical terms, and Roboto's notice. See the detailed attribution and license inventory for provenance and unresolved checks. Keep original notices intact.
