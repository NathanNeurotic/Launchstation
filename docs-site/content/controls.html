Controls

Every screen is driven by the same ten inputs: D-pad (or left stick), Confirm, Cancel, Triangle, Square, L1/R1, L2/R2, START, SELECT and R3. Button labels follow your Confirm button setting, so Circle and Cross swap if you change it.

Confirm and cancel

Settings > Input > Confirm button chooses which face button confirms; the other cancels everywhere (default Circle confirms, Cross cancels). Footer hints and dialogs show the right icon automatically. The setting is saved as GUI_Swap_Keys. Both controller ports are read at once and a USB keyboard can be used in parallel.

Text Editor

See Text Editor navigation. In short, with the keyboard hidden: D-pad moves, L1/R1 go to line start/end, L2/R2 page, Square selects, Confirm shows the keyboard, SELECT toggles it, Triangle or START opens the menu, Back exits. With the keyboard shown: D-pad picks a key, Confirm types, Back deletes, Square caps, L1/R1 move the cursor left/right, L2/R2 up/down, Triangle or SELECT hides the keyboard.

USB keyboard

Enable Settings > Input > USB keyboard (off by default; the setting is USBKBD_USED). Wherever the dashboard expects a controller, the keyboard acts as a virtual gamepad in addition to the real ones, so you can navigate the whole interface. Most buttons have more than one key because keyboards differ:

In addition, Enter is always Confirm and Space is always Cancel, whichever way your Confirm button is mapped. While typing a name (rename, new folder, keyboard dialogs) the keyboard types directly: Left/Right/Home/End move the caret, Backspace and Delete erase, Enter accepts and Esc cancels. In the Text Editor it types straight into the document. A different USB keyboard driver or key map can be set under Settings > Input > USB keyboard. There is no mouse support.
