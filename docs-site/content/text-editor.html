Text Editor

A dashboard-native editor for configuration, scripts, argument lists and other text files.

Typical files

CNF, CFG, TXT, INI, CHT, PBT, JS, LUA, XML, TOML, YAML, YML and ARG files can be opened from File Browser.

Navigation

D-pad MoveL1/R1 Line start/endL2/R2 PageSquare SelectTriangle Options

The full current path is shown beneath the document title and scrolls when necessary. Footer hints are intentionally compact enough for the PS2 safe width.

Editor menu

Save, Save As, New, Open, Switch Document, Start/Stop Selection, Select All, Copy, Cut, Paste, Line Endings, Go to Start, Go to End, Launch with Arguments, Close and Exit are available from Triangle. START opens the Dashboard menu; unsaved documents are confirmed before leaving.

On-screen and USB keyboards

Confirm opens the virtual keyboard. SELECT hides/shows it. USB keyboard input is supported when enabled and its driver is available.

Launch with arguments

Write one argument per line and choose Launch with these arguments…. The editor validates the buffer and hands argv to the same loader used elsewhere.
