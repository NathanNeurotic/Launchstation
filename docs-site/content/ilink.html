iLink / FireWire

IEEE 1394 mass storage is demand-loaded and presented as a normal dashboard/browser device.

Opening iLink

If the card says Not checked, it remains selectable. Confirm invokes the iLink stack; the dashboard refreshes after the probe. If no usable bridge/disk is detected, the card becomes unavailable instead of remaining in an ambiguous state.

File Browser

Once ready, iLink behaves like the other BDM-style filesystems for browsing and file operations. Test ordinary directory listing first when diagnosing a game-launch problem.

Neutrino ISO source

Current Neutrino includes an ilink backing-store driver. A selected .ISO is handed off with the live iLink device stack preserved so quick-boot can consume the existing mount.

Hardware notes

Bridge chipsets, disk formatting and enclosure behavior vary. A useful report includes the console model, bridge/enclosure, filesystem, whether File Browser works, exact wLaunchELF build hash and Neutrino version.
