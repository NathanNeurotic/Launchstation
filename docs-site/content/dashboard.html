Dashboard

A PS2-style front end over classic wLaunchELF capabilities.

Sections

SectionPurpose
HomeRecent/favorite or configured quick actions. Home shortcuts can be hidden.
AppsApplications discovered from configured scan folders.
Files / DevicesOne merged section with a remembered Devices/File-list view toggle.
ToolsFile Browser, Text Editor, HDD tools, POPStarter/Neutrino entry points, system info, cloud actions and utilities.
SettingsAppearance, Home/apps, sound, input, launching, storage/devices, network and system options.

Navigation model

L1/R1 changes top-level sections. The active tab uses a stable monotonic selector animation; the earlier fast overshoot was removed because it could look like top-edge video flicker on interlaced displays.

Files and Devices

Files and Devices share one section. SELECT toggles view and the choice is remembered. Show unavailable devices controls confirmed-unavailable cards. Devices that are merely Not checked remain selectable so opening them can load their driver.

Reserved status areas

Unsaved settings, confirmation toasts and clock/date have defined lanes instead of drawing over one another. Long labels and notifications use bounded scrolling.

Presentation

Selection style, icon backing, theme motion, clock placement, BGM and related options are configurable. See Display, Themes & BGM.
