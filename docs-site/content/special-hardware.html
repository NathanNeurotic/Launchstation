PSX, Deckard & RetroGem

R3Z carries hardware-specific behavior for later slim consoles, DESR PSX systems and RetroGem-equipped consoles.

Deckard PS2 models

On Deckard-family slim systems without a conventional internal expansion-bay HDD path, internal HDD/ATA cards are hidden where they are not meaningful. This avoids presenting dead hardware paths as normal choices.

Sony PSX / DESR

PSX-specific devices such as xfrom: and dvr_hdd0: are exposed only on compatible DESR hardware. The exploit installer also recognizes PSX-family targets and chooses the appropriate installation/header behavior.

RetroGem Game ID

The project includes RetroGem Game ID support for PixelFX RetroGem workflows. This allows compatible launch paths to communicate game identity to the video hardware where configured.

Dual HDD / ATA groundwork

The standard build includes dual HDD/ATA support groundwork for ongoing development. Treat experimental combinations as hardware-test territory and report exact console/device details when something differs from the primary paths.

Hardware-specific reports

Always include the exact console model. Behavior that is correct on a fat SCPH with DEV9/HDD can be intentionally different on a Deckard slim or a DESR PSX.
