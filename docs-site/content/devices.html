Why Not checked is selectable

A demand-loaded driver cannot know whether hardware is absent until it runs. A Not checked device therefore remains navigable; opening it triggers the existing lazy loader. A confirmed Absent card can be displayed but is skipped by focus navigation.

USB units

USB is labeled USB / MASS. The implementation discovers available units and does not treat mass0: as a permanent identity.

Hide unavailable devices

When unavailable-device display is disabled, those cards are removed from both drawing and navigation indices; the focus rectangle does not pass through hidden/disabled cards.
