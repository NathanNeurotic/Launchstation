Getting Started

From a fresh download to a working dashboard and first launch.

1. Download the current build

Use the repository's Latest automated build. Choose APP_LAUNCHSTATION.zip for the standard build or APP_LAUNCHSTATION-DS.zip for DualShock USB/Bluetooth support. Extract the app folder, which includes its packed ELF and title.cfg. Matching PSU packages can be installed to a memory card with PSU Paste. Optional sidecars are available in the repository's res/ directory.

Keep related files together when practical
BGM and native Google Drive support use sidecar files. They are optional; basic dashboard and file-manager operation does not require them.

2. Put the ELF on a bootable device

mc0:/
└── APP_LAUNCHSTATION/
    ├── LAUNCHSTATION.ELF
    └── BGM.ADP        optional

You can also launch from USB/MASS, another homebrew launcher, or any supported filesystem that can read the ELF.

3. First boot

The dashboard opens with project defaults. Storage stacks are demand-loaded: a device card may say Not checked until you open it. That does not mean the device is absent.

Confirm OpenBack ReturnL1/R1 SectionsSELECT Files/Devices view

4. Open your first device

Go to Files / Devices. Select USB / MASS, MMCE, MX4SIO, iLink, Internal HDD (APA), ATA/exFAT or another available card. If its driver is not loaded, opening the card triggers the lazy loader and refreshes state.

5. Launch an ELF or index applications

ELFs launch directly from File Browser. For the Apps section, configure Settings → Home & applications → Application folders. Only listed roots are scanned; defaults include mc:/APPS/, mc:/APP_LAUNCHSTATION/, mass:/APPS/ and mass:/APP_LAUNCHSTATION/, one subfolder deep.

6. Optional game-image launching

  • PS1 / POPStarter: select a .VCD.
  • PS1 / Ember: select a .CUE, .BIN or PS1 .EXE directly inside <Ember directory>/games/<Game>/. The umbrella can be named anything.
  • PS2 / Neutrino: select a .ISO.

The file format/layout chooses the core automatically; there is no “preferred PS1 core” switch.

7. Save settings

The dashboard tracks actual serialized differences. Unsaved state remains visibly accented. Leaving Settings or using its menu lets you save, discard or continue editing.
