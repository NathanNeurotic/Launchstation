Display, Themes & BGM

The dashboard is PS2-inspired but fully configurable. One theme holds every visual value (background, colours, selection style, tile shape, corners, font, icons, clock and the app-artwork wallpaper). Pick a built-in preset, change any value with the controller, export the result as a theme folder, and load theme folders that you or others made on a PC. Nothing needs recompiling. The File Browser, HDD Manager, Text Editor and dialogs all follow the same active theme.

Built-in themes

There are 18 presets under Settings > Appearance > Theme preset. OSD Classic is the default. Left/Right switches preset immediately; Confirm opens the list, previews each preset as you move, keeps it on Confirm and restores your previous theme (even an edited one) on Back. A preset you have edited shows as Name (edited).

Older saved selections midnight resolve to Blue Mist and lightshow to OSD Classic. Light Streaks and Drift Clouds remain available as custom background types. An unmodified preset is stored by name only, so it follows improvements to that preset in later builds.

Every background is drawn procedurally from a few GS primitives; none of them uses or needs Sony BIOS data. The PS2-inspired scenes follow behaviour documented by the osdbits OSDSYS reverse-engineering notes (menu tunnel, tower heightfield, illegal-disc clouds, System Configuration clock, colour-swap selection).

The OSD orbs

OSD Classic, OSD Minimal and System Clock draw the PS2 main menu's orbs as the clock they are. Seven orbs, one per weekday, ride one circle whose plane slowly tumbles; their light trails show where the circle has been, so the sphere appears. They follow the console clock: all seven meet in one bright orb at :00, split into two groups at :30, three at :20 and :40, four at :15 and :45, five at :12, :24, :36 and :48, and six at :10 and :50. The sphere is small at the top of the hour and grows as the hour goes by. At 0% background motion the orbs hold still; below 50% the trails are shorter. If the real-time clock stops changing or becomes invalid, the orbs keep moving on the shared visual clock (they do not invent a date or time), and a valid clock tick re-anchors them.

Selection presentation

Selection style (Customize theme > Tiles & menus): Solid bar, Accent bar, Outline or Text colour (how the PS2 system menus mark the selection). Selected and unselected device cards share one geometry; focus adds emphasis without resizing or reflowing the card. Corners can be Square, Soft or Round and apply to panels, dialogs and list rows; Glow adds soft light behind focused items.

Application tile styles

Settings > Appearance > Customize theme > Tiles & menus > Tile style. Memory card is the default for every built-in preset (and for old configurations or theme folders without tile_style).

  • Memory card (memory_card): a narrow PS2 card silhouette with a cut corner, grip ridges and a recessed device label strip. Artwork fits inside the card face.
  • Rounded (rounded): the rounded rectangular tile, independent of panel corners.
  • Chamfered (chamfered): an eight-sided tile with clipped corners.
  • Floating object (floating): artwork or the fallback icon floats above a pool of light with a solid focus marker. The selected icon rises and gently bobs; bobbing stops with reduced/off animation. This is a 2D treatment, not a rotating 3D icon.
  • Crystal slab (crystal): a faceted block with lit top and shaded side faces.

Tile style applies to Home and Applications artwork, including fallback icons and initials. Changes preview immediately and take part in the normal Save/Discard session. Reset style restores the preset's values. Exported themes include tile_style; customized dashboard configurations store it as Theme_tile_style.

Icon backing

Settings > Appearance > Control icon backings (default On) shows or hides theme-derived badges behind face-button and D-pad symbols and behind quick-action chips. Button symbols come from the built-in vector atlas, so no external icon PNGs are needed.

Icons

Applications that have artwork keep using it. Others get the Default app icon (Customize theme > Icons): Application (default, a PS2-style program icon on a tile in the theme colours with the device as a badge), Device (the device's icon) or Initials (coloured tile with the app's initials). Icon colour is Text colours, Accent or Monochrome. Custom app icon image... (or app_icon =) uses your own PNG; up to 128x128 is kept and alpha is supported. If the file is missing or broken the built-in icon is used.

Fonts and text

Font is Roboto (default, bundled, three pre-rasterised sizes) or System (Launchstation's own 8x16 font, smoothed; it follows an external .FNT chosen as System font file and covers the Latin-1 characters used by the language files). Text size runs 90% to 115% in 5% steps; Bold and Text shadow are switches. Arbitrary TTF files are not loaded on the console; to change Roboto, regenerate the atlas on a PC with scripts/gen_dash_font.py.

Clock and date

The clock (Customize theme > Clock) is Off, Standard (larger time over a small date) or System (light grey, even weight, seconds, date in the console's format, like the PS2 menus). Position is Header or Footer (in the footer it sits left of the button hints and hides itself where hints need the space). Hours is System, 24-hour or 12-hour; Seconds is on or off; Date is System, YYYY/MM/DD, MM/DD/YYYY, DD/MM/YYYY or Off. With Hours and Date on System, the console's own settings are used. The format rows are disabled while the clock is Off. File metadata keeps its seconds independently of the clock setting. For a console with a dead clock battery see Settings.

Motion

  • Background motion (Appearance): 0% to 200% in 10% steps, default 100%. 0% freezes the scene; 200% doubles its speed. Lower values use lighter detail where available.
  • Menu animation: 0% to 200%, default 100%. 0% makes transitions instant; higher values lengthen them.
  • Panel transparency: 0% removes menu panels and 100% makes them fully opaque (it edits the Panels colour's opacity).

Top tabs, selection movement, OSD orbs and marquee effects use bounded smooth animation on a measured visual clock. The former fast sinusoidal header overshoot was removed because it could appear as top-of-dashboard video flicker on interlaced displays. Older configurations that stored motion as 0/1/2 load as 0%/50%/100%.

Background types

Customize theme > Background offers 19 types: Solid colour, Gradient, System tunnel, Blue mist, PS2 towers, Disc error red, Orbit lights, Clock ring, Memory card grid, Boot lines, Wireframe cubes, Data stream, Memory card tiles, Brushed console, Ribbons, Crystal, Light streaks, Drift clouds and Wallpaper image. Colour is the solid colour or gradient top (for scenes it tints walls, clouds, lights or grid lines); Second colour is the gradient bottom or the scene's base. Brightness runs 10% to 200%; CRT scanlines adds an understated line pattern over the background only. With the Crystal background, optional PSBBN-style layers THEME/background.png, stars1.png and stars2.png in the dashboard folder are used when present (scripts/prepare_psbbn_theme.py builds them from a texture pack you own; no third-party artwork is embedded).

Colours

Customize theme > Interface colours: Text, Secondary text, Muted text, Selected text, Accent, Selection (with opacity), Panels (with opacity; 0 = no panels), Borders (with opacity; hidden when Panels is transparent) and Warnings. A row opens the colour editor drawn beside the live dashboard: Up/Down choose Red, Green, Blue, Opacity or the PS2 quick picks (OSDSYS blue, cyan, menu indigo, clock-rod blue, disc-error red, configuration-title yellow and neutral greys); Left/Right ±1; L1/R1 (or L2/R2) ±16; Confirm keeps; Back restores. On confirm the theme is checked and a text colour too close to its background is replaced so the menus stay readable, with a message when this happens.

Custom wallpaper: 4:3 aspect ratio

Make your wallpaper on a 4:3 canvas. Use 640 × 480 PNG to preserve detail, or 320 × 240 for a smaller, lower-memory image like the starter example. Launchstation preserves aspect ratio, center-crops wider or taller inputs, and fills the screen. The decoder keeps wallpapers inside a 640 × 512 box, so a 4:3 source can retain 640 × 480 pixels. Smaller sources are not enlarged during decoding. A 640 × 480 texture uses about 1.17 MiB of decoded memory, four times the 320 × 240 option. This improves image detail at the existing output modes; it does not itself change the video output resolution. The 640 × 448 logical UI coordinate system is not the required artwork ratio.

Format and composition tips

  • Format: PNG, maximum file size 1.5 MB and source dimensions 2048 × 2048. A non-interlaced RGB or indexed 320 × 240 PNG is an easy choice. Interlaced PNGs are accepted only up to 256 × 256. Grey, palette, RGB, 8- or 16-bit, with or without alpha, all load.
  • Safe area: keep important subject matter away from the extreme edges. CRT overscan and screen centering vary, and dashboard panels or hints may cover parts of the image.
  • Contrast: use a dark or subdued background behind text and adjust theme brightness, panel opacity and text colours if needed.
  • Other ratios: 320 × 256 is 5:4, and 320 × 224 is 10:7; both are supported inputs but are not the ideal 4:3 canvas. 16:9 sources are cropped horizontally.
  • Memory: theme images (wallpaper and default app icon) share eight cache slots and are loaded once on first use; missing, too-large or broken files are remembered and skipped, and the gradient or built-in icon is drawn instead.

How to enable one

  1. For a single image, open Settings > Appearance > Customize theme > Background > Wallpaper image..., then choose a PNG and save your Settings changes. This switches the background type to Wallpaper image.
  2. To load the example theme, place theme.cfg and background.png together inside a folder under THEMES/ next to the Launchstation ELF (or in the dashboard configuration folder). Choose Settings > Appearance > Theme files & resets > Load theme from folder..., select that folder and save.

For a theme.cfg file, background = image and image = background.png select the static wallpaper. The separate wallpaper = focused option uses the artwork of the selected application and is not needed for a custom static image. Missing or invalid wallpaper files fall back to the theme gradient.

Application artwork background

With Customize theme > Artwork background > App artwork background = Focused app (and Application artwork enabled under Home & applications), the focused application's cover is laid over the background on Home and Applications, cross-faded on focus changes and dimmed by Artwork dimming (0% to 90%, default 65%). It reuses the artwork cache and never loads a file itself; apps without artwork just show the theme background.

Theme folders

<dashboard folder>/THEMES/
└── MyTheme/
    ├── theme.cfg        required
    ├── background.png   optional (name it anything; see image =)
    └── app.png          optional default application icon (app_icon =)

Settings > Appearance > Theme files & resets offers Theme name..., Export theme to folder... (writes a complete theme.cfg to the first writable root immediately; this does not save the Settings session), Load theme from folder..., Reset entire theme (back to the preset it started from) and Restore default theme (OSD Classic). Theme folders are looked up first in THEMES/ beside the Launchstation ELF, then in THEMES/ next to DASHBOARD.CNF. Both are read only from devices whose driver is already running and only when you choose Load, never at startup. The loaded theme is copied into DASHBOARD.CNF so it keeps working if the folder is removed later, except for its images, which are read from the folder. A theme.cfg larger than 16 KB is not read.

Where the theme is stored

The active theme lives in DASHBOARD.CNF as Theme_* keys: Theme_preset = <id> with Theme_custom = 0 for an unmodified preset, or Theme_custom = 1 plus one Theme_<key> per value for an edited theme. Edits are written about a second after the last button press (and always before an application starts), so adjusting a colour does not write the memory card on every step. Older builds ignore these keys; a DASHBOARD.CNF without them loads OSD Classic. LAUNCHELF.CNF is not touched by theme edits.

Background music

BGM.ADP ships in the current rolling ZIP/PSU packages and is optional for standalone ELF installs; put it next to the executable when installing manually. It must be a mono PS-ADPCM file with the APCM header (at most 1 MiB, complete 16-byte blocks, loop-enabled for continuous music), not a renamed Ogg/WAV/MP3. It is read from the folder the ELF booted from. A missing, malformed or unreadable file never prevents the dashboard from booting and is tried once per audio session (turn Background music off and on to retry). The loader waits until background IO is idle and never starts a storage stack just to look for music. Interface sound effects are embedded in the ELF. Both have their own switch and volume (default on, 80%) under Settings > Sound.

Website cursor orbs

The GitHub Pages site has a separate top-header cursor-orb toggle. Orbs are on by default on desktop and off by default on mobile/coarse-pointer devices. Your choice is saved locally, and switching off stops the animation loop. This does not change the PS2 dashboard theme.

Restoring defaults

  • Square on a theme row resets just that setting to the preset value.
  • Reset ... at the end of each editor group resets that group only (resetting Tiles & menus does not change panel opacity).
  • Theme files & resets > Reset entire theme returns to the preset the theme started from; Restore default theme returns to OSD Classic.
  • Appearance > Reset appearance restores screen calibration, motion, animation and OSD Classic together; Screen calibration > Reset screen settings restores video mode Auto and a centred picture.
  • Deleting the Theme_* lines from DASHBOARD.CNF also restores the default.

Fonts and text weight

Font offers Roboto (default), System and optional Emotion Engine. Style selects Regular or Bold. Emotion Engine includes original Regular/Bold outlines; Roboto and System retain synthesized bold. Existing font IDs and defaults are preserved.
