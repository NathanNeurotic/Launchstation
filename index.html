What this project is
Launchstation is a maintained fork of the R3Z branch of wLaunchELF (see Credits), keeping the power-user roots of LaunchELF/uLaunchELF/wLaunchELF while adding a PS2-style dashboard, safer device handling, modern storage paths, searchable app discovery, richer file operations, MMCE workflows, PC interoperability and external game-core handoffs. The dashboard is the only interface; the proven wLaunchELF file, HDD and launch logic runs underneath it.

Design goals

  • Device-agnostic launching. Work from the device the user actually browsed instead of assuming mass0 or mc0.
  • Demand-load expensive stacks. Drivers and networking stay out of startup until needed.
  • Keep classic functionality. Dashboard actions wrap proven filesystem and browser operations instead of discarding them.
  • Visible state. Not checked, absent, busy, unsaved changes and background work are explicit.
  • Never overwrite what cannot be recovered. Backup recovery produces new, verified files; updates keep a .BAK copy and refuse unverifiable releases.
  • Hardware-first validation. CI catches structural/link/layout regressions; device behavior is still verified on consoles.

Feature map

AreaHighlights
DashboardHome, Files, Tools, Settings (switch with L1/R1); Applications library nested in Home with Grid/List/Carousel views and a Last folder shortcut; 18 built-in themes, custom colors, wallpapers, clock, background music and animation.
File managementDashboard File Browser with copy/cut/paste, rename, delete, folders, PSU create/extract, VMC mounting, timestamp tools, bookmarks, sorting, name/title/details views, an image viewer (PNG/JPG) and a Text Editor.
StorageMemory cards, USB/MASS, MMCE, MX4SIO, iLink, internal APA/PFS, ATA/exFAT, PC CARD CompactFlash on early Japanese models, UDPFS network storage and the PSX flash/DVR drives.
Game imagesPS1 VCD via POPStarter; PS1 CUE/BIN/EXE folder layouts via Ember; PS2 ISO via Neutrino with optional per-game profiles; RetroGem Game ID output.
BackupsMMCE card export/history, skip-unchanged behavior, IGR-triggered backup, optional native Google Drive copy-only sync, verified recovery to new files.
NetworkOn-demand FTP, PS2Link and UDPFS; staged PC ISO transfers; Internet clock sync; HTTPS update check and in-app updater.
Hardware toolsMemory card exploit installer (retail, PSX, DEX, custom signed ELF), HDD Manager with APA header injection, software clock for dead CMOS batteries, PS3/PS4 DualShock support in the -DS variant.
LanguagesEnglish, Spanish, Italian, French, German, Polish, Portuguese, Brazilian Portuguese and Hungarian; external .LNG files can override messages.
