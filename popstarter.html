PS1 VCD Launching · POPStarter

Open a POPStarter-compatible .VCD in the File Browser and Launchstation validates it, builds the argument POPStarter expects for that device, finds the POPStarter ELF and starts it.

External software, your files

POPStarter is maintained separately and is not shipped with Launchstation. You supply POPSTARTER.ELF (and whatever BIOS/modules it needs) and your own VCD images. Its compatibility rules still apply. PS1 .CUE/.BIN/.EXE images use Ember instead: the file format picks the core.

Preferred POPStarter

Settings > Launching > Disc & image loaders > POPStarter sets the preferred POPSTARTER.ELF. This path is always tried first (mc:/… is tried as mc0: then mc1:). Under the same page, Disable POPStarter support (default Off) makes Launchstation refuse VCD launches before touching the image, the loader or any driver.

Supported VCD locations

Where the VCD isRule
USB (massN:/usbN:), MMCE, MX4SIO, exFAT HDD (ata0:)The VCD must be inside a POPS folder at the root of the device (case-insensitive), for example usb0:/POPS/Game.VCD. Subfolders below POPS are passed through in the argument; POPStarter’s own naming rules still apply.
Internal APA HDD, partition named __.POPS…Any .VCD in that partition, e.g. hdd0:/__.POPS/Game.VCD; the file name is what is passed.
Internal APA HDD, any other partition whose name begins __. or PP.The VCD must be named IMAGE0.VCD at the partition root (the one-game-per-partition layout).
iLink, UDPFS, memory card, PC CARD CF, discNot supported. Copy the VCD to one of the devices above.

A VCD elsewhere on a supported device is refused with “POPStarter does not support that VCD path”, because POPStarter locates its image by name.

Where the POPStarter ELF is looked for

  1. Your explicit path from Settings (if set and the file can be opened).
  2. FAT-style devices: <the VCD’s own device>/POPS/POPSTARTER.ELF, e.g. usb0:/POPS/POPSTARTER.ELF, mmce1:/POPS/POPSTARTER.ELF, mx4sio:/POPS/POPSTARTER.ELF, ata0:/POPS/POPSTARTER.ELF.
  3. Internal HDD: hdd0:__common:pfs:/POPS/POPSTARTER.ELF, then hdd0:__system:pfs:/launcher/POPSTARTER.ELF.

Candidates that cannot be opened are skipped in order. A candidate that opens but is not an ELF stops the search with “POPStarter ELF is not an ELF” instead of silently falling through to another copy.

Device-aware argument construction

Launchstation does not pass POPStarter the browser filename. For FAT-style devices the VCD path below POPS/ is turned into POPStarter’s uLE:XX.… form with the extension replaced by .elf; for __.POPS partitions the file name is used, and for one-game partitions the argument names the partition. HDD paths pass through the partition-aware hdd0:<partition>:pfs: launch form and the owning partition is carried through the hand-off.

Validation before launch

The file is opened and checked: at least 1,102,672 bytes, the first four bytes 41 00 A0 00, and the POPS signature (kHn, with matching repeated bytes) at offset 1,024. A failing file is reported as “This file isn’t a POPS VCD”. A cannot-open error is reported separately.

Hand-off, IOP reset and saves

POPStarter follows the generic Reset IOP before launch setting (default on, under Settings > Launching): with it on, Launchstation resets the IOP and loads POPStarter from the device; with it off it keeps the already-mounted storage stack. This differs from Neutrino and Ember, which always use their own keep-IOP hand-off. When the VCD or the POPStarter ELF lives on the HDD, the partition mounts are released first. POPStarter keeps its own virtual memory cards (.VMC files managed by POPStarter), so MMCE card switching does not apply.

RetroGem Game ID

If Game ID launch signal for discs is on (default), the ID read from the VCD’s SYSTEM.CNF boot line, then the shared PS1 timestamp database, then the file/partition name, is drawn for a RetroGem just before the hand-off. No MMCE command is sent. See RetroGem Game ID.

Troubleshooting

  1. “Cannot find POPStarter ELF”. Set the path explicitly, or place POPSTARTER.ELF where the fallback list expects it.
  2. “VCD path unsupported”. Move the VCD into POPS/ at the device root (or an HDD POPS partition).
  3. “This file isn’t a POPS VCD”. The image is truncated, not a VCD, or is a raw BIN/CUE. For CUE/BIN use the Ember layout.
  4. Starts and returns to a black screen / game fails. Compare with the same VCD launched from POPStarter’s own launcher on the same device; then try toggling Reset IOP before launch. Report exact build hash, POPStarter version and device.
  5. HDD VCD not found. Names matter: __.POPS partitions list files by name; other partitions need exactly IMAGE0.VCD.
