Internal HDD

Launchstation keeps the classic APA/PFS hard-disk workflow of the PS2 expansion bay: browse partitions, open files inside them, launch programs from them, and manage the disk with the HDD Manager. A FAT/exFAT disk is a different device (ATA / exFAT).

Supported consoles

The expansion-bay HDD needs a fat PS2 with a network adapter / HDD unit. Slim consoles that report ROM 2.20 or newer have no bay, so Launchstation hides the HDD and ATA cards there automatically. The PSX (DESR) has its own recorder disk and appears as dvr_hdd0:, see PSX, Deckard & RetroGem.

Opening the HDD

The device card is named Internal HDD (APA) (hdd0:). It starts Not checked: selecting it loads DEV9, the APA/PFS drivers and the HDL information module, then probes hdd0:. On success it reads APA partitions; otherwise No browsable APA storage found. You can also enable Settings > Storage & devices > Start devices automatically > Auto-start internal HDD so it is ready at boot (off by default). The first unit is hdd0:; a second disk would be hdd1:. By default Hide HDD1 + ATA1 keeps the second unit out of the list; change it under Settings > Storage & devices > Internal HDD / ATA units.

Path forms

FormMeaning
hdd0:/The partition list in the File Browser.
hdd0:/PARTITION/path/to/fileBrowser path: Launchstation mounts the partition as PFS and shows the contents.
hdd0:PARTITION:pfs:/path/to/fileLaunch form used for executables, sidecars and external cores; the owning APA partition is carried through IOP teardown and hand-off so an ELF on PFS stays reachable.
pfs0:/path, pfs1:/pathThe mounted-filesystem name inside the IOP while a partition is open. Do not store these; they are session-specific.

Browsing mounts a partition read/write. Starting a program from the HDD mounts its partition read-only for the loaded ELF, except Ember, which gets a writable write-through mount so its save files persist (see Ember).

What you will see

  • PFS partitions (__common, __sysconf, __net, user partitions) – browsable file systems.
  • HDL games (PP.<ID>..<TITLE>) – installed disc images. They are raw game data and are not browsable files. The HDD Manager can show the title and disc information on request (R1) and rename the game.
  • System – __mbr is never touched. Any partition whose name begins with __ (for example __common, __system, __sysconf) is reserved: the HDD Manager will not remove it.
  • Not accessible – partitions that are neither PFS nor HDL.

Common partition workflows

  • __common is the traditional shared application/data partition. POPStarter is searched in hdd0:__common:pfs:/POPS/POPSTARTER.ELF and hdd0:__system:pfs:/launcher/POPSTARTER.ELF when the VCD lives on the HDD (see POPStarter).
  • The folder-date organizer also works in hdd0:/__common/ as well as memory-card roots, see Saves & timestamp tools.
  • Header injection writes HDD-OSD / PSBBN metadata into a PFS partition’s APA header, see Inject header.

Game images on the APA disk

Launchstation does not start a Neutrino PS2 ISO from hdd0:; use a USB, MMCE, MX4SIO, iLink, exFAT (ata0:) or UDPFS source instead. PS1 VCDs can run from POPS partitions on the HDD, and Ember games can run from a PFS partition.

ATA / exFAT is separate

An exFAT or FAT32 disk in the bay is the exFAT HDD device (ata0:, ata1:). It uses the BDM/FatFs path, is detected only when the disk is not APA formatted, and is a normal ISO source for Neutrino. The APA and ATA stacks can be resident together, but one physical disk is only one or the other. Never format a disk from Launchstation to “switch” between them without a backup.

Power off and safety

  • Use Tools > Power off (or the console power button) so the HDD stack can close open PFS files and shut DEV9 down cleanly. Pulling power while a partition is mounted can corrupt it.
  • Partition operations (create, remove, rename, format) are permanent. Back up first and keep known-good header folders for bulk injection.
  • If the disk was formatted by another tool, the HDD Manager reports The HDD is not APA formatted; if nothing answers it reports No HDD was found.

Troubleshooting

  1. Card says “No browsable APA storage found”. Check the HDD unit power and ribbon, then run Check again. A disk that is exFAT/FAT belongs on the ata0: card.
  2. HDD card is missing. The console is ROM 2.20+ (no bay), the Hide HDD setting hides that unit, or the build lacks it. Hold SELECT at boot to show all devices.
  3. Slow or stuck at “Reading the HDD”. Disks with very many partitions take a long time to scan; wait for the list to finish before pressing buttons.
  4. Nothing works after switching MMCE/MX4SIO or network. Those stack changes reset the IOP and clear device probes; reopen the HDD card.
  5. Report the console model, drive/adapter, partition layout, exact build hash and whether the classic path works.
