Credits, Third-Party Projects & Licenses

LAUNCHSTATION builds on decades of PS2 homebrew. This page distinguishes upstream code, checked-in components, compiled dependencies, external programs launched by the user, referenced projects and community contributions. It was reviewed against the repository on 26 October 2026.

Project lineage and maintainers

wLaunchELF_R3Z by R3Z3N / Saildot4K is the direct upstream base. The earlier wLaunchELF / uLaunchELF / LaunchELF developers and ps2dev community retain credit for the underlying launcher lineage. johnson-cooper created this fork and transferred maintenance; NathanNeurotic (Ripto) is its current maintainer.

Special thanks to techwritescode for collaboration (and for the PS2BUILD SDK that builds this project), TnA for insight and support, oMrRexD for PC/R3Z ecosystem collaboration and reference, zackcage6 and FitthFox for dashboard and File Browser testing and UX feedback, and R3Z3N / Saildot4K for sd2psx/MMCE firmware guidance (which card switches MMCEMAN can make) and PSX hardware feedback. Contributors and testers also appear in the repository's Git history, merged pull requests and release notes.

PC CARD CompactFlash foundation

Credit to mihhru and his PS2CF project for the early-PS2 CF PIO/ATA driver foundation and host tests (pinned commit recorded in iop/pccf/VENDORED.md). The isolated source port in iop/pccf/ preserves component notices and the PS2SDK-derived hardware license (AFL-2.0, Marcus R. Brown); its host-test header stubs come from the PS2BUILD SDK headers with their notices intact. The driver is embedded in the standard and DualShock builds and loaded on demand; native CF browsing and console compatibility remain under development, and this credit does not claim verified support.

External projects and dependency inventory

Attribution below does not mean every third-party program is distributed by LAUNCHSTATION. The role of each project is specified: vendored (source in this repository), compiled (built from upstream or an SDK package into the ELF), embedded binary, external (separate program you install), service, or reference.

Vendored and checked-in source

  • wLaunchELF_R3Z — vendored base. Direct upstream by R3Z3N / Saildot4K; earlier LaunchELF, uLaunchELF and wLaunchELF contributors retain credit.
  • ps2dev / PS2SDK — vendored and compiled. Local variants of the memory-card manager (iop/vmcman, from iop/memorycard/mcman at commit ff7c5f9, with jimmikaelkael's mcman copyright retained), APA/PFS (iop/ps2hdd_osd, patched to track the HDD unit per open slot), the ATA/BDM driver (iop/ata_bd), hdl_info, xparam (Deckard), dev9_poweroff, the EE libhdd and libiopreboot sources in ee_libs/, plus the SDK libraries and IRX modules listed below. AFL-2.0 unless a file header says otherwise.
  • ps2-mmce/mmceman — vendored (iop/mmceman). MMCE driver lineage and device protocol. Credit the upstream MMCE developers, including Wisi and Maximus32 for earlier SIO2 work.
  • RiptOPL / Open-PS2-Loader — vendored. The updated usbd-ra USB driver (iop/usbd-ra, built with MINI_DRIVER) imported during USB recovery; also relevant to the OPL IGR return workflow.
  • Neutrino SMAP driver by Rick Gaiser and contributors — vendored and compiled. iop/udpfs_smap is Neutrino's iop/smap at commit 06188cc with receive-tail and startup corrections (see iop/udpfs_smap/ORIGIN.md); AFL-3.0 retained in iop/udpfs_smap/LICENSE.
  • PS2Link — vendored. iop/ps2host is the PS2Link file-I/O server (the host: filesystem), copyright Tord Lindstrom (pukko) and adresd, under the PS2Link License referenced in its file headers. The PC-side PS2Client is a separate program.
  • SMB network shares (smb:, smb1:) — the device design and SMB2.CNF format are Ronnie Sahlberg’s, from saildot4k’s wLaunchELF_R3Z PR #63, reimplemented here (src/smb_cnf.c, src/smb_shares.c). smb: uses smb2man.irx from libsmb2 by Ronnie Sahlberg and André Guilherme, based on jimmikaelkael’s smbman (embedded binary; driver sources AFL-3.0, libsmb2 library LGPL-2.1; wLaunchELF branch d61b781; see iop/__precompiled/SMB2MAN.md). smb1: uses jimmikaelkael’s PS2SDK smbman with Open-PS2-Loader’s fixes (vendored, iop/smbman, AFL-3.0).
  • ps2ftpd — vendored. Jesper Svennevid's FTP server at iop/oldlibs/ps2ftpd/, accompanied by Academic Free License v2.0.
  • DS34 controller drivers — vendored. Inherited PS3/PS4 controller support (iop/ds34usb, iop/ds34bt, src/pad_ds34.c), with credit to Alex Parrado and the R3Z/PS2 community. Built only into the DualShock package.
  • PS2BUILD SDK audio package — embedded binary and compiled. The SDK audio.irx driver is embedded unchanged and the audsrv-compat EE client (an audsrv-compatible API on top of audio) is linked for interface sounds and background music; AFL-2.0. It replaces the previously vendored ps2sdk audsrv.
  • QR Code generator library (C) by Project Nayuki — vendored as src/qrcodegen.c for the Google Drive link screen; MIT License.
  • Roboto font (Copyright 2015 Google Inc., Apache-2.0) — the glyph atlases in src/dash_font_data.c are rasterized from Roboto Regular by scripts/gen_dash_font.py. Notice: docs/licenses/Roboto-COPYRIGHT.txt.

Compiled dependencies and SDK components

  • PS2BUILD SDK by techwritescode and contributors — build tool and source of the SDK core packages (AFL-2.0 per the SDK's own license file) and world packages. Its LLVM/Clang EE and IOP toolchain builds the release.
  • Mbed TLS 3.6.7 — compiled from the upstream release tarball (SHA-256 pinned) by scripts/build_cloud_tls.sh; Apache-2.0 (upstream also offers GPL-2.0-or-later). Used for HTTPS in Google Drive and the updater.
  • libjpeg-turbo 3.1.3 — compiled by scripts/build_jpeg.sh for the active toolchain; IJG, BSD-3-Clause and zlib licenses per its LICENSE.md. Used by the JPEG viewer (src/dash_jpeg.c); see also the Independent JPEG Group.
  • libpng and zlib — compiled from PS2BUILD world packages for PNG artwork and wallpapers; see the SDK's license files.
  • gsKit and dmaKit — compiled dashboard graphics libraries; gsKit credits Chris "Neovanglist" Gilbert and contributors, under upstream Academic Free License version 2.0.
  • PS2SDK EE libraries — compiled from SDK packages: libmc, libpad/padx, libkbd, libcdvd, fileXio, libpatches, libpoweroff, libdebug, libsecr, ps2ips and the C library glue (newlib) and compiler runtime of the active toolchain. Licenses are those of the SDK packages.
  • PS2SDK IOP modules from SDK packages — embedded binary, unchanged: iomanX, fileXio, DEV9, PS2IP/SMAP, netfs, mcman/mcserv, sio2man/padman, libsd, cdfs, ps2kbd, the BDM family (bdm, bdmfs_fatfs, usbmass_bd, mx4sio_bd, iLinkman, IEEE1394_bd), PS2FS, poweroff, secrsif and the PSX DVR/flash modules (dvrdrv, dvrfile, xfromman, xfromserv, extflash). These keep the licenses of their SDK packages; bdmfs_fatfs bundles the FatFs library.
  • PS2IP socket RPC server — ps2dev contributors; vendored under iop/ps2ips_rpc/ with its Academic Free License 2.0 and pinned-source notice. Built as a separate IOP target for clock sync and Internet clients.
  • PS2SDK v1.0 DEV9/PS2IP pair — embedded binary in iop/__v10, preserved from oMrRexD's builds as the optional Legacy Ethernet drivers fallback.
  • UDPFS ministack and ioman — embedded binary. The prebuilt udpfs_ministack.irx and udpfs_ioman.irx in iop/__precompiled are the client half of the UDPFS protocol served by pcm720's UDPFSD; their exact upstream revision is not recorded in this repository.
  • Public CA root certificates — embedded data: Google Trust Services roots R1 to R4 (include/cloud_google_roots.h) for Google, and Sectigo Public Server Authentication Root R46 and ISRG Root X1 (res/WLE-UPDATE-CA.PEM) for GitHub updates. No endorsement by the certificate authorities is implied.

External programs and services

  • Neutrino — external. PS2 ISO loader maintained independently; the ELF and its configuration are not bundled. SMB ISO launches use its SMB backend by Ronnie Sahlberg (ps2max32/neutrino PR #236, built on usmb2).
  • POPStarter — external. krHACKen's independent PS1 VCD launcher, not included with Launchstation.
  • Ember — external. Gageformer's PS1 core, not bundled; beta builds have their own distribution terms.
  • PS2Link / PS2Client — external PC side of the remote-access ecosystem.
  • UDPFSD server — external. pcm720's PC-side UDPFS server referenced by supported network storage workflows.
  • OSDMenu / launcher — reference. pcm720's KELF forwarders and PS2 boot workflows; the embedded low-memory loader layout follows its approach.
  • KELFTool — reference. xfwcfw's separate KELF tooling for PS2KEYS.dat and KELF workflows. The memory-card installer signs on the console from a user-supplied PS2KEYS.dat; no keys are distributed.
  • HDD-OSD Icon Generator — reference. CosmicScale's helper for HDD/APA icon resources; not bundled.
  • PixelFX RetroGem — external hardware for the optional RetroGem Game ID feature.
  • rclone — external. Used by the optional Windows Cloud Relay helper on the PC; not bundled.
  • Google Drive API / OAuth — service. Public protocols used by the original native Drive client; no Google endorsement is implied.
  • GitHub releases and REST API — service used by the update check; the time server 0.pool.ntp.org is used only by the optional clock sync. See the Privacy Policy.
  • oMrRexD / R3Z PC ecosystem — reference. Compatibility and integration reference for PC-side remote commands and transfers (PS2-COMANDO / PS2-RECEBER).
  • SD2Cloud — reference. Related backup ecosystem used for capability comparison only; the native Drive client does not incorporate SD2Cloud source.

Additional bootloader and boot-environment projects

  • PS2BBL by El_isra and PS2BBLE by R3Z3N — independent PS2 bootloader projects, not synonymous with Launchstation's exploit installer.
  • LoadBOOTer — a named option in the inherited memory-card exploit installer; authoritative author and source are not verified in this repository audit.
  • ESR, FreeMcBoot and PSBBN — separate boot tools, software environments or compatible formats referenced in the docs; their code is not implied to be distributed. The memory-card installer payloads in exploits/ are inherited binaries whose individual authorship is not documented in this repository.

Further library and subsystem credits

The EE/IOP graphics, filesystems, audio and networking stacks include PS2SDK and upstream library contributors. Check the originating source file headers, included package metadata and the relevant upstream license notices when redistributing builds or source archives. The PS2Key material, user games, PS1 BIOS and external emulator executables are not supplied by this repository. The origin and license of the bundled background-music sidecar (res/music.sad), the interface sound effects (res/sfx) and the button glyph PNGs (res/icons) are not recorded in the repository and should be confirmed before redistribution outside the project's own packages. The default 8x16 bitmap font (src/font_uLE.c) is inherited from uLaunchELF.

Cloud implementation boundary

The Google Drive client is implemented against Google's published APIs; SD2Cloud source code was not incorporated. External launchers remain independently maintained and licensed.
