HDD Manager & APA Header Injection

The HDD Manager lists the APA partitions on hdd0:, creates, removes and renames them, edits a partition’s header SYSTEM.CNF, formats the disk, and injects HDD-OSD / PSBBN style headers from a __Headers folder.

Everything here writes to the disk

Create, remove, rename, edit, format and inject change partition tables and boot-visible metadata immediately. Back up anything that matters first. Powering off while an operation runs can corrupt the disk.

Opening it

Use Tools > HDD Manager, or press Triangle on the Internal HDD (APA) card in the Files tab’s device cards and choose HDD Manager. If the HDD drivers cannot start you will see No HDD (“Is an HDD connected?”). An unformatted or non-APA disk shows The HDD is not APA formatted and offers Format HDD only. The HDD Manager also runs on the PSX, but formatting is disabled there (The PSX internal HDD cannot be formatted from Launchstation).

Partition list and game information

The list shows the original APA identifiers as classic wLaunchELF did, without querying HDL titles on every cursor move. Controls: D-pad moves, L2 / R2 page, OK opens the Actions menu, L1 opens HDD status, R1 loads Game info for the selected HDL partition (title and disc information; the partition keeps its APA name). The details panel shows the partition type (PFS partition, HDL game, System or Not accessible), size, and for PFS partitions their usage, which is read in the background (“Reading usage…” or “Could not be mounted”). Reserved partitions show “Reserved for the system. It cannot be changed.”

The size picker moves in 128 MB steps with Left/Right, 1 GB with L1/R1 and 10 GB with L2/R2. The classic menu’s Expand command exists in the source but is permanently disabled; partition expansion is not available.

Inject header

For a selected PFS partition, Inject APA header… first asks for the header source: usb:, mmce0:, mmce1: or udpfs: (its driver starts on demand). The source must contain __Headers/<matching partition name>/, a flat folder of header files. Launchstation waits up to three seconds for the source to appear.

Injection modes

ModeBehavior
This partitionInject only the selected partition from its matching header folder.
All matching partitionsScan __Headers and inject every folder whose partition already exists. Incomplete folders are ignored and reported.
Matching, and create missing onesInject existing matches, then ask for each missing valid partition: Create it (you pick a size), Skip it or Stop. A summary shows Injected / Created / Skipped / Failed.

Example system.cnf

BOOT2 = pfs:/boot.kelf
VER = 1.00
VMODE = NTSC
HDDUNITPOWER = NICHDD

Safety

  • Keep known-good header folders and a backup before bulk operations; “Matching, and create missing ones” can create partitions.
  • A disk with hundreds of partitions takes minutes to scan. Wait for the list to finish; there is no interrupt command yet.
  • Do not remove a partition just because it looks unfamiliar: __-prefixed names belong to the system and PSBBN, and the HDD Manager protects them from removal.
