HDD Manager & APA Header Injection

Classic APA management is retained, with header injection tools for rebuilding or provisioning HDD-OSD style partition metadata.

Partition operations

The HDD Manager can inspect APA partitions and exposes creation/removal/rename/expand/format and related maintenance operations where supported. These actions are destructive; confirm the target disk and partition before writing.

Browse partitions and game information

The partition list displays original APA identifiers, as in classic wLaunchELF, without querying HDL game titles on every cursor movement. Scroll or page using the D-pad and L2/R2. For a selected HDL game partition, press R1 — Game info to load its title and disc information explicitly. The selected partition stays identified by its APA name; long names and startup IDs are fitted inside the details panel. PFS usage can still load in the background. L1 opens HDD status.

Inject Header

For a selected PFS partition, the operations menu can inject header resources from device:/__Headers/<matching partition name>/. Supported source families include USB, MMCE and UDPFS.

Injection modes

ModeBehavior
This partition onlyInject only the selected partition from its matching header folder.
Matching partitionsScan __Headers and inject folders whose partitions already exist.
Matching and create missingInject existing matches, then prompt before creating each missing valid partition.

Example system.cnf

BOOT2 = pfs:/boot.kelf
VER = 1.00
VMODE = NTSC
HDDUNITPOWER = NICHDD

Safety

Header injection changes boot-visible partition metadata and can optionally create partitions. Keep known-good header folders and a backup of anything important before bulk operations.
