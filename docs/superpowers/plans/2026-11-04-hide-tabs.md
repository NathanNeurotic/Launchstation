# Hide Section Tabs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A theme option "Section tabs: Shown/Hidden" that stops drawing the dashboard top bar while L1/R1 switching and the header clock keep working.

**Architecture:** One `u8 tabs` field in `DashTheme`, persisted and reset through the same key table the other theme enums use. `dashDrawHeader()` returns after drawing the clock when the field is `DASH_TABS_HIDDEN`. Settings exposes it on Theme → Style.

**Tech Stack:** C (PS2 EE, ps2sdk/gsKit), host tests in Python that compile slices of the sources with the system C compiler (run under WSL Ubuntu on this machine).

**Spec:** `docs/superpowers/specs/2026-11-04-hide-tabs-design.md`

## Global Constraints

- Tabs for indentation, `.clang-format` on touched hunks.
- No new mechanisms: follow the `clock_pos` plumbing exactly.
- Presets keep `DASH_TABS_SHOWN`; only user themes can hide the bar.
- Header clock still draws when hidden and `clock_pos == DASH_CLOCKPOS_HEADER`.
- No layout change for screen content.

## Review Focus

- Old DASHBOARD.CNF/theme.cfg with no `tabs` key loads as Shown (Task 1 test).
- `tabs = 7` or `tabs = garbage` in a file clamps to Shown, never reads past `tabs_ids[]` (Task 1 test).
- "Reset style" restores Shown while leaving Colours untouched (Task 1 test).
- Switching Hidden → Shown after changing sections: the selector animates from its last drawn position to the current tab (existing `dashApproach` converges in a few frames). Acceptable; no code.
- Settings "Section tabs" row must remain reachable with the bar hidden (Settings is a section; D-pad navigation inside the page is unaffected). Covered by `test_settings_navigation.py` id walk.
