# Launchstation documentation index

Status key (as of 2026-10-26):

* **Reference** - describes current behaviour; kept up to date with the code.
* **Policy** - a safety or design rule that is still in force.
* **Historical** - an audit, plan or report written at a point in time. It carries a dated status note at the
  top saying what was resolved, what is open and what was superseded. Do not treat its checklists as live.
* **Legacy** - inherited from LaunchELF/uLaunchELF/wLaunchELF; kept for provenance, not maintained for this fork.

The user-facing manual is the website in `docs-site/` (published at
<https://nathanneurotic.github.io/Launchstation/>). Pages there are generated from `docs-site/content/*.html`.
