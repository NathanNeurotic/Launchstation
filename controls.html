Controls

Button labels follow configured confirm/cancel mapping, so the face button can differ by region or preference.

Dashboard

ControlAction
ConfirmOpen focused item, device or page.
BackClose or return.
L1 / R1Previous / next top-level section.
SELECT in Home > ApplicationsCycle Grid, List and Carousel views.
STARTOpen the global dashboard menu.
R3 on Home (without SELECT)Toggle the background-only display; press R3 again to restore the interface. SELECT + R3 still follows the configured launch key.
Triangle / MenuContext action; Settings exposes save/discard flow.

Visible navigation

L1/R1 cycles Home, Files, Tools and Settings. Home contains Applications and Last folder; Files opens directly into a persistent native browser. Classic MISC commands are under Tools. Returning to Files preserves the folder and selection.

File Browser

ControlAction
ConfirmOpen folder/file or launch a supported executable/image.
SquareMark/unmark entry.
TriangleOperations menu.
BackParent folder / close at root.

Text Editor

See Text Editor navigation. L1/R1 moves to line boundaries with the keyboard hidden; L2/R2 pages vertically. The compact footer keeps all six hints inside the dashboard safe width.
