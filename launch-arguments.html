Launch Arguments

Launchstation can cache a user argument list, consume a sidecar .arg file, or launch directly from a Text Editor buffer.

File Browser workflow

  1. Select a Text Editor-supported argument file.
  2. Open its operations menu and choose Launch ELF with Args.
  3. Launchstation parses and caches the argument lines in memory.
  4. Select the target ELF. The cached arguments are appended after the normal handoff path.

Text Editor workflow

The Text Editor offers the same action for the current in-memory buffer. Unsaved edits are used, which makes it convenient for testing launch flags without repeatedly writing the argument file.

Automatic sidecar arguments

For an ordinary ELF launch, Launchstation checks for a same-directory sidecar whose base name matches the ELF, for example:

APPS/
├── BOOT.ELF
└── BOOT.arg

If arguments were already cached manually through the browser/editor action, the sidecar is ignored for that launch.

Format and limits

RuleCurrent limit
One non-empty lineOne user argument
User arguments12 lines
Characters per argument255
Total cached argument text2,048 bytes including terminators

Line endings are stripped. Other characters on each line are preserved.

argv[0]

The target executable still receives the normal selected/handoff path as argv[0]; cached user lines follow it. External-core paths such as Neutrino build their own controlled argument set and do not consume a stray normal-ELF argument cache.
