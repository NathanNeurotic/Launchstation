Dashboard: Current Navigation

LAUNCHSTATION now has four visible top-level tabs. Applications live under Home; Files is the actual native File Browser, not an extra landing page.

Four top-level tabs

TabBehavior in current builds
HomeContinue carousel, pinned/recent/favorite applications, Applications library shortcut, Last folder shortcut when available, and optional configured launch-key shortcuts.
FilesOpens the native File Browser directly inside the dashboard frame. Browse drives and folders, operate on files and return to the same folder/selection after switching tabs.
ToolsFile Browser, Text Editor, MISC commands, USB unit diagnostics, HDD Manager, exploit installer, network tools, MMCE/IGR and Google Drive functions where enabled.
SettingsAppearance, Home/app library, sound, input, launching, devices/MMCE, network, and system settings.

Home and Applications

Select Applications from Home to enter the full library without adding a fifth top-level tab. The library keeps its Grid/List/Carousel views, favorites, pins, filtering and recents. SELECT cycles application views. Add or remove a favorite from the application options; the result also displays a toast.

Last folder appears on Home after the browser has a valid remembered location. Optional launch-key shortcuts can be disabled without removing the Applications and Last folder navigation shortcuts.

Files and device discovery

Files is a persistent browser tab using the same engine as the modal browser opened from Tools. The root lets you select devices and start lazy drivers; Not checked is not the same as absent. The old separate Devices landing view and Files landing page are not additional visible tabs.

Asynchronous USB reads can complete after a tab change. Input remains guarded until outstanding reads finish, rather than treating a tab switch as permission to poll PAD immediately.

Navigation

L1/R1 cycles Home, Files, Tools and Settings. START opens the global menu; File Browser supports context actions and multi-selection. The visible section count is four even though compatibility code retains older internal section identifiers.

Status and visuals

Clock, notifications, confirmation toasts, animation, BGM, screen calibration and themes have explicit display settings. Dashboard double buffering reduces horizontal scanout tearing, but passing CI does not establish every console/display combination is flicker-free. See Themes & BGM and Troubleshooting.
