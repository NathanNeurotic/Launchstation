Privacy Policy

Launchstation is free, open-source PlayStation 2 homebrew. It has no accounts, no analytics and no servers of its own. This page explains the little data it handles and where it goes.

Summary

  • Launchstation does not collect, sell or share personal data.
  • There is no telemetry, advertising or tracking.
  • Everything Launchstation stores stays on your own PS2 storage (memory card, USB, HDD and similar).
  • Network features run only when you use them, and talk directly to the services listed below.

Google Drive backup (optional)

If you choose Link Google Drive, you authorize Launchstation on a phone or computer with a short code from Google. Launchstation requests only the https://www.googleapis.com/auth/drive.file scope, which lets it see and manage only the files it creates (your memory-card backups in the WLE-MMCE-Backups folder). It cannot read the rest of your Google Drive.

Google returns an authorization (refresh) token, which Launchstation saves in WLE-CLOUD.TOK beside its settings on your own device. The token is sent only to Google, over verified HTTPS, to upload, list or download your backups. Launchstation's developers never receive your token, your backups or your Google account details. Uploaded files carry a private checksum (wle_sha256) so unchanged backups are not uploaded twice.

To stop access, choose Disconnect Google Drive in Launchstation, which deletes the local token, and/or remove Launchstation at Google Account > Third-party access. Files already uploaded stay in your Drive until you delete them.

Launchstation's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Other network features

  • Check for updates contacts the GitHub API and downloads release files from GitHub when you ask it to. GitHub's own privacy statement applies to those requests.
  • Clock synchronization, when used, asks public time servers (such as time.google.com, time.cloudflare.com or pool.ntp.org) for the current time. No personal data is sent.
  • Network file sharing (host/UDPFS and similar) connects only to computers you configure on your own network.

Like any internet request, these services can see your IP address. Launchstation adds no identifiers of its own.

Children

Launchstation does not knowingly collect data from anyone, including children.

Changes and contact

Changes to this policy are published on this page and in the project's GitHub repository. Questions can be raised as a GitHub issue or sent to the support email shown on the Google consent screen.
