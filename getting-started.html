Getting Started

Install the correct app variant, open the four-tab dashboard and begin with the actual file browser.

1. Download the current package

Use the verified rolling release. Choose APP_LAUNCHSTATION.zip for standard PS2 controls or APP_LAUNCHSTATION-DS.zip for the inherited PS3/PS4 controller variant. Matching .psu packages support memory-card installation via PSU Paste. Device-specific hardware testing is separate from successful compilation.

2. Install the app folder

mc0:/
└── APP_LAUNCHSTATION/
    ├── LAUNCHSTATION.ELF
    ├── title.cfg
    ├── BGM.ADP
    └── WLE-UPDATE-CA.PEM

Extract the ZIP as a folder or install the matching PSU. Preserve existing settings and customized sidecars if upgrading. The DS package has its own folder and LAUNCHSTATION-DS.ELF. BGM is optional to run; the current packages include it.

3. Use the four main tabs

Use L1/R1 to move between Home, Files, Tools and Settings. Home includes the Applications library and, once known, Last folder. Files opens the native browser immediately; choose a drive or folder there. Tools contains classic MISC commands and specialist utilities. Current UI map.

4. Open a device

Start in Files, at the device root. Memory cards, USB/MASS, MMCE, MX4SIO, internal HDD/ATA, iLink and configured network devices have distinct availability rules. Not checked usually means opening the device must start a lazy-loaded driver. USB units can change numbering. Avoid simultaneous writes across recovery or backup operations.

5. Find applications

Use Home > Applications for the library, or browse and launch an ELF directly from Files. Under Settings > Home & applications > Application library, configure application folders and refresh the library. The default roots currently include mc:/APPS, mc:/BOOT, mass:/APPS and mass:/BOOT, one level deep. Applications outside these folders can still launch from Files.

6. Optional external cores

Neutrino is needed for PS2 .ISO; POPStarter for PS1 .VCD; Ember for PS1 .CUE/.BIN/.EXE in its save-safe game-folder layout. These external programs and game/BIOS data are not bundled. Read the specific guide before your first handoff.

7. Configure MMCE backups if needed

Choose a local backup destination under Settings > Storage & devices > MMCE backups. Link Google Drive only if desired. A verified snapshot can be recovered to a new file, not directly over an active MMCE card. See MMCE recovery.

8. Save and update safely

Settings has explicit Save/Discard semantics. Before upgrading, retain a backup of your configuration and current working ELF. The native updater verifies the rolling package and stages changes, with an original executable recovery copy for rollback.
