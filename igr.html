IGR Return & Backup

OPL’s Exit to (in-game reset) can return to Launchstation through a small helper, WLE-IGR.ELF. On the way back Launchstation can back up every MMCE memory-card image, optionally copy the history to Google Drive, and then continue to the destination you chose.

Why a helper is needed

OPL starts its Exit-to program in a minimal environment that cannot read the sd2psXtd filesystem or most BDM devices directly. WLE-IGR.ELF is a tiny trampoline: it resets the IOP, loads only the storage family needed for the configured Launchstation path (memory card, MMCE, USB, MX4SIO, iLink, exFAT HDD or internal HDD), waits for that file to appear (up to 24 tries, a quarter second apart), and starts Launchstation with -wle-igr plus the backup folder. If it cannot find Launchstation it exits to the PS2 system menu instead of hanging. The helper is built in and its copy is patched with your paths at install time; it is rewritten and byte-verified after install.

Setting it up

  1. Choose a backup folder (Settings > Storage & devices > MMCE backups > Backup folder) or pick one when prompted. It must not be inside an MMCE MemoryCards tree.
  2. Run Tools > OPL IGR automatic MMCE backup (or MMCE backups > IGR helper) and choose Install / update. Launchstation installs or updates the helper where OPL can launch it and shows the exact path to enter as OPL’s Exit-to.
  3. Set that path in OPL’s settings. Re-run the install if you move Launchstation or change the backup folder. Remove helper deletes the helper copies Launchstation manages and leaves existing backups untouched.

The settings page reports the helper as Current, Outdated, Not installed or Partial / mixed by comparing installed bytes with this build’s helper and your backup folder.

What happens on return

  1. OPL exits to the helper; the helper starts Launchstation.
  2. If Automatic sync is Local backup or Local + Google Drive (default: Local backup), Launchstation starts MMCE and backs up every valid .mcd under both mmce0:/MemoryCards and mmce1:/MemoryCards, not only the active card, because named and GameID cards cannot be reconstructed after the reset. Unchanged cards are skipped, judged by a fingerprint of each card’s directory instead of a full read, with a full compare at least every 8 backups; details of the fingerprint, verification, retention and layout are on MMCE Backup History.
  3. Only for Local + Google Drive, new history is then uploaded (copy-only). This needs an already linked Google account, otherwise the Drive step reports an error. Drive is a second phase and never replaces the local copy.
  4. Launchstation continues to the After IGR, open choice: Launchstation (dashboard, default), the PS2 system menu (OSDSYS), or an Application you select (its device is started first).

Only a launch carrying the IGR flag takes this path; a normal boot never runs IGR routing or backups.

After-IGR behavior

Settings > Storage & devices > MMCE backups has After IGR, open and IGR application (used when the destination is Application). If the chosen application cannot be started, Launchstation stays in the dashboard and shows IGR: could not start device for … or no after-IGR application selected.

Failure policy

Backup and cloud problems are shown as a status message on the dashboard and never block the return:

  • IGR: automatic MMCE backup disabled – Automatic sync is Off.
  • IGR: no MMCE backup destination configured – choose a Backup folder and reinstall the helper.
  • IGR: MMCE driver unavailable; backup skipped / no MMCE MemoryCards tree found.
  • IGR MMCE backup: N changed, N unchanged, N failed (N cards), followed when applicable by Drive: N uploaded, N present, N failed or the Drive error text.

The design never reports a failed write or failed cloud step as a success. The helper itself can only fall back to the system menu if it cannot find Launchstation.

Limits and tips

  • IGR backup applies to MMCE cards; if you do not use MMCE the helper is just a return trampoline.
  • Use a stable destination (USB or HDD). A backup folder on a device that is not started during IGR will not work; the driver family for that device must be loadable after the reset.
  • After updating Launchstation, re-run Install / update if the status reads Outdated.
  • Hardware timing between OPL, the adapter and the helper has only been host-tested; report firmware version and boot device if an IGR return does not reach Launchstation.
