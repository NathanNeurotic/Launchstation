Text Editor

A dashboard-native editor for configuration files, scripts, argument lists and notes. It runs inside the dashboard frame with the active theme, supports up to eight open documents, an on-screen keyboard that docks at the bottom of the screen, and a USB keyboard.

Opening the editor

  • From the File Browser: Confirm on a supported file, or Triangle > Open in Text Editor.
  • From Tools > Text Editor (starts with no document; the first menu offers New document, Open... and Exit).
  • From Application options > Start with arguments... and Edit metadata (opens or creates the .arg / .cfg file).

Supported file types

TXT, CHT, CFG, INI, CNF, PBT, JS, LUA, XML, TOML, YAML, YML and ARG open directly from the File Browser. Through Open... inside the editor you can pick any file. Files larger than 512 KB are refused; a document can grow to that size. The editor remembers each document's own line endings (CR/LF (PC), LF (Unix) or CR (old Mac)) and keeps them on save unless you change them in the menu.

On-screen keyboard

Confirm (or SELECT) docks the virtual keyboard. Its layout comes from Settings > Input > On-screen keyboard layout (QWERTY by default; also ABC, Dvorak, AZERTY, QWERTZ, ABNT).

USB keyboard

With Settings > Input > USB keyboard on (it is off by default), a USB keyboard types directly into the document: printable keys and Enter, Tab and Backspace insert/delete, and the arrow keys, Home/End, Page Up/Page Down and Delete move or edit as expected. Escape opens the editor menu. Optional driver and key-map files are set on the same page. Typing is paused while background storage work is using the IOP. See Controls for the keyboard-as-pad map used elsewhere.

Launch with arguments

Write one argument per line and choose Launch with these arguments.... The editor validates the buffer (empty lines are skipped; at most 12 arguments, 255 characters each, 2,048 bytes total) and, if valid, closes and asks which application to start. Unsaved edits are used, so you can test flags without writing the file first. A message appears if the text is not usable. Details and the sidecar rules are on the Launch Arguments page.

Notes on saving

Saving writes the file; failures show File not saved with a hint that the device may be read-only or full. Discs cannot be written (use Save as to choose another place). After editing metadata for an application, that app is re-read automatically. When you leave the editor, its last document's folder becomes the browser's Last folder.
