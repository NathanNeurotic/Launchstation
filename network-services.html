FTP, PS2Link & Remote Control

Network services are included in the standard build but remain demand-driven so normal boots are not slowed by an always-on network stack.

FTP

Start FTP from the dashboard Tools/network area when you actually need file transfer. The service uses the configured network stack and should be stopped/rebooted when you want to return to the smallest resident footprint.

PS2Link

PS2Link support remains available for development-oriented transfer/launch workflows. Like FTP, it is not started during an ordinary dashboard boot.

R3Z remote-command compatibility

The project follows the existing oMrRexD R3Z/PC-client command ecosystem where possible rather than creating a second incompatible desktop client for the same operations.

Recommended troubleshooting sequence

  1. Confirm physical Ethernet/link and adapter availability.
  2. Confirm IP, netmask and gateway.
  3. Start only the intended service.
  4. Test basic connectivity from the PC.
  5. Then debug the higher-level command/transfer request.

Network project credits

PS2Link is a ps2dev project. The retained legacy ps2ftpd sources credit Jesper Svennevid and carry Academic Free License version 2.0. The Credits & Licenses page lists their respective roles.

Network exposure

These are homebrew console services, not hardened internet-facing daemons. Keep the PS2 on a trusted local network and do not forward service ports from the public internet.
