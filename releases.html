Rolling changelog summary

  • Infinite wrap-around navigation for dashboard lists and file-browser views.
  • Safer replacement when pasting over existing files (old copy preserved until replacement is verified).
  • Copy/delete overlays now show cleaner progress with filename, remaining size in MB and smooth progress fill.
  • Cross-device copy reliability improvements for short reads/writes and storage handoff timing.
  • Clock-save and storage-load reliability fixes across restart and card/driver transitions.

Full details: latest release notes · CHANGELOG.md.

Notes

The -DS packages enable inherited PS3/PS4 controller support; standard packages keep the standard PS2 pad driver. CI success and package integrity do not replace real hardware validation. If a new rolling build regresses on your console, keep a known-good baseline and report console model, source hash and reproduction steps.
